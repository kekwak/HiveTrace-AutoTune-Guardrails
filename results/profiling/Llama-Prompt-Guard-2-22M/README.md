# meta-llama/Llama-Prompt-Guard-2-22M — профиль и узкие места

Веса из зеркала `hipocap/Llama-Prompt-Guard-2-22M`, sha256 `model.safetensors` начинается с `5120e30b`, совпадает с другими зеркалами, лицензия Llama 4.

- На один forward: ~500 ядер GPU и ~3750 операций PyTorch на CPU, из них ~1500 — `view`, `as_strided` и т.п..
- Матричные операции идут в fp32 `volta_sgemm`, без tensor cores.

## Узкие места

1. **Накладные расходы CPU.** Задержка почти не зависит от длины входа: ~31 мс от 64 до 512 токенов, GPU занят 18–60% времени, остальное ждёт, пока CPU запустит следующую операцию.
2. **Работа с относительными позициями, не зависящая от входа.** В каждом слое проекции эмбеддингов относительных позиций и умножение на них, при 16 токенах это ~40% времени GPU.
3. **Поэлементные операции attention** на длинных входах: `add`, `gather` по относительным позициям, `div`, `masked_fill`, softmax — 53% времени GPU при 512 токенах, attention считается обычными операциями, без fused-ядра.
