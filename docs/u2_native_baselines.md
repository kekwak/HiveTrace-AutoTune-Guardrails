# Скорость и качество семи штатных эталонов

Рабочий код находится в `research/quantization`. В конфигурациях сохраняются
штатные eager-режимы У1 из `49809cc`. Prompt Guard использует закреплённое зеркало
`hipocap/Llama-Prompt-Guard-2-22M`. Коэффициенты ускорения из BF16/FP8 эксперимента
относятся к компилированным вариантам.

На поде нужен RTX 5090, доступ к закреплённым весам (включая ShieldGemma),
`uv` и подготовленный каталог корпуса качества У1 с `manifest.json` и
`corpus.jsonl`. По умолчанию корпус ищется в `/workspace/u2-native/quality`.
Его можно безопасно перенести с Mac по SSH в выделенный каталог. Скрипт собирает
среду `team-rtx`, загружает закреплённый корпус скорости и строит индексы У1.
Ревизии и хэши входов сохраняются в артефактах.

```bash
bash scripts/u2_native_baselines.sh prepare
bash scripts/u2_native_baselines.sh smoke gliner
bash scripts/u2_native_baselines.sh run
```

`smoke` проверяет скоростную сетку и короткий корпус качества для выбранных
моделей. `run` использует обе проверки и выполняет полный BF16/FP32 baseline
скорости и замер качества на batch 1. Повторный запуск с теми же конфигами
переиспользует готовые архивы. Предыдущие частичные попытки сохраняются рядом
с новой попыткой. Чтобы оставить несколько запусков с разной аппаратурой,
задайте им разные `U2_NATIVE_ROOT`.

С локальной машины забирайте артефакты по мере готовности. Команду можно
повторять, пока она не завершится с кодом 0. ZIP сначала проверяется под
временным именем.

```bash
python -m u2_quant.native_baselines collect \
  --host root@POD_IP --port POD_SSH_PORT --identity ~/.ssh/runpod_u2 \
  --remote-dir /workspace/u2-native/runs --out ../u2_5090_runs/native-eager

python -m u2_quant.native_baselines summary \
  --directory ../u2_5090_runs/native-eager \
  --out ../u2_5090_runs/native-eager/summary.json
```

Итоговый JSON содержит полный разрез мер скорости и качества, фактическую
точность, среду, закреплённые источники и SHA архивов. Сравнивайте общий FNR/FPR
вместе с покрытием и областью применения модели. Laya проверяет запрос
опасных инструкций, ShieldGemma оценивает заданную политику, Prompt Guard
специализируется на атаках на инструкции, а Koala оценивает свои восемь
категорий модерации. Датасет качества и сырые запросы хранятся отдельно от
публичных архивов.
