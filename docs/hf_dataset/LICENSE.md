# Лицензии и атрибуция

## Фрагменты Wikipedia

Источник: `wikimedia/wikipedia`, снимок 20231101,
ревизия `b04c8d1ceb2f5cd4588862100d08de323dccfbaa`.
[Карточка закреплённого источника](https://huggingface.co/datasets/wikimedia/wikipedia/blob/b04c8d1ceb2f5cd4588862100d08de323dccfbaa/README.md).

Авторы текстов — участники Wikipedia. У каждой записи `source=wikipedia` сохранены
название статьи, её URL и ссылка на историю авторства, исходный снимок и позиции фрагмента.
Преобразование: выбор непрерывного фрагмента из очищенного текста источника без изменения написания.
Тексты публикуются на условиях Creative Commons Attribution-ShareAlike 3.0 Unported:

- [Описание CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- [Полный текст условий CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/legalcode)

При дальнейшем распространении сохраняйте атрибуцию, ссылки на условия и сведения об изменениях.
Исходная карточка также указывает GFDL, предупреждая, что некоторые тексты доступны только
по Creative Commons. Здесь не заявляется, что любой фрагмент можно выбрать для использования по GFDL.

## Синтетические тексты

Детерминированные шаблонные записи `source=synthetic` предоставляются по
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Внешние LLM API для их создания не использовались. Эта отметка не распространяется на Wikipedia-фрагменты.

## Метаданные и ограничения

Составитель: vXofi. Авторские описания, списки ID и измерительные метаданные этого выпуска
предоставляются по CC BY-SA 3.0; ранее существовавшие права на материалы источников сохраняются.
Ни Wikimedia, ни владельцы перечисленных моделей не заявлены авторами или одобрившими этот набор.
Весов и файлов токенизаторов в выпуске нет; ссылки на модели не изменяют их лицензии.
