# Guardrails Speed EN/RU

Общий корпус нагрузки для сравнения скорости конфигураций guardrail-моделей.
**1600 разных текстов, четыре бакета по 400. Это не размеченный safety-бенчмарк.**
Не использовать для accuracy/F1/FNR или заявлений о сохранении качества безопасности.

Версия: **u1-speed-v3**. Подготовка и пересечения проверены на CPU.
Веса не загружались; исполнимость длинных запросов на T4 этим корпусом не подтверждена.

## Бакеты

Границы относятся к **полному входу конкретной модели** после её prompt/template/schema
и добавления специальных токенов, а не только к пользовательскому тексту.

| Бакет | Полный вход, токенов | Обязательные модели |
| --- | --- | --- |
| B1 | 1–512 | Все восемь моделей ниже |
| B2 | 513–1024 | Четыре декодера |
| B3 | 1025–2048 | Четыре декодера |
| B4 | 2049–4096 | Четыре декодера |

Декодеры: HaloGuard1-Gen-0.8B, HiveTraceGuard-Pro, OpenGuardrails-Text-4B-0124, ShieldGemma-2b.
Энкодеры: GLiNER Guard Omni, KoalaAI/Text-Moderation, Laya English, Llama Prompt Guard 2 22M.
Ревизии и ограничения закреплены в [contracts.json](contracts.json).
Для Llama явно выбрано публичное зеркало `hipocap/Llama-Prompt-Guard-2-22M`;
тождество оригиналу Meta и историческому запуску коллеги не установлено.

Один и тот же список текстов внутри бакета используется всеми его моделями.
Никакого padding ради бакета, скрытой усечки или переписывания текста под модель.
Распределение не равномерное: из-за длинных политик декодеров B1 содержит короткие
пользовательские тексты. Например, у Llama выбранные полные входы имеют **13–89 токенов**.
Это не проверка всего encoder-диапазона до 512. Распределения: [REPORT.md](REPORT.md).

В каждом бакете: 150 Wikipedia EN + 150 Wikipedia RU + 50 synthetic EN + 50 synthetic RU.
Между бакетами нет повторов. Не следует сравнивать latency разных моделей как сравнение
качества: токенизация, политики и задачи моделей различаются.

## Загрузка

Доступ публичный; HF token не нужен. Установить `huggingface_hub` обычным способом.
Версионный тег `v3` фиксирует первый выпуск. Для строгого воспроизведения используйте
полный commit SHA этого выпуска вместо тега и сохраняйте SHA в результатах.

```python
import hashlib
import json
from pathlib import Path
from huggingface_hub import snapshot_download

root = Path(snapshot_download(
    "__REPO_ID__", repo_type="dataset", revision="v3", token=False,
))
print("Dataset commit:", root.name)
manifest = json.loads((root / "manifest.json").read_text())
for filename, expected in manifest["files"].items():
    assert hashlib.sha256((root / filename).read_bytes()).hexdigest() == expected, filename

records = [json.loads(line) for line in (root / "corpus.jsonl").read_text().splitlines()]
by_id = {row["id"]: row for row in records}
ids = json.loads((root / "buckets/B1.ids.json").read_text())
texts = [by_id[i]["text"] for i in ids]  # порядок из общего списка бакета
```

Для просмотра через `datasets` доступен единственный split `benchmark`, не `train/test`:

```python
from datasets import load_dataset
ds = load_dataset("__REPO_ID__", revision="v3", split="benchmark")
```

Перед измерением заново подготовить входы модельным адаптером и сверить длины/хеши
с индексом. Загрузка корпуса сама по себе не воспроизводит prompt/schema или адаптер.
Конфигурация input preparation должна соответствовать закреплённому контракту;
хеши input contract, tokenizer assets и исходника подготовки включены в метаданные индексов.
Хеш массивов IDs/масок считается как SHA256 от UTF-8 JSON с `ensure_ascii=False`,
`sort_keys=True`, `separators=(",", ":")`.

## Файлы

- `corpus.jsonl`: текст хранится один раз; поля `id`, `text_sha256`, `text`, `language`,
  `source`, `provenance`, `format`. ID — SHA256 исходного UTF-8 текста.
- `buckets/B*.ids.json`: упорядоченные списки ID, по 400.
- `indices/<model>.jsonl`: длины user/total input, хеши IDs/масок, допустимость входа;
  только выбранные применимые строки: 1600 для декодера, 400 для энкодера.
- `indices/<model>.meta.json`: источник, ревизия, версии, хеши и связь с полным исходным индексом.
  Это компактные публикационные индексы, не полный рабочий индекс пула на 48 000 строк.
- `manifest.json`: контрольные суммы всех остальных файлов, состав, распределения и происхождение выпуска.
- `contracts.json`, `REPORT.md`, `LICENSE.md`: контракты, сводка, атрибуция и лицензии.

В пакете нет весов, токенизаторов, токенов доступа, локальных путей, trace или рабочих архивов.

## Происхождение и отбор

Источник: [wikimedia/wikipedia](https://huggingface.co/datasets/wikimedia/wikipedia/tree/b04c8d1ceb2f5cd4588862100d08de323dccfbaa),
ревизия `b04c8d1ceb2f5cd4588862100d08de323dccfbaa`, снимок `20231101`.
Использованы первые EN/RU shards: `20231101.en/train-00000-of-00041.parquet`
и `20231101.ru/train-00000-of-00021.parquet`.

Из статей до модельной токенизации выделены непрерывные фрагменты по границам слов.
Не более одного фрагмента на статью; точные дубликаты удалены. Это не семантическая
дедупликация всего корпуса. В каждой записи сохранены статья, URL, история авторства,
позиции фрагмента и SHA256 исходного текста статьи из снимка.

Синтетика создана детерминированно без внешних LLM API: обращения, диалоги, цитаты,
структурированные записи. Seed 42. Пул из 48 000 текстов пересечён по фактическим
полным длинам всех обязательных моделей, затем заполнены фиксированные языковые/источниковые квоты.
ID и байты выбранных текстов совпадают с локальным проверенным выпуском;
его fingerprint и SHA256 manifest включены в публичный manifest.

## Ограничения

Корпус не представляет production-трафик. Квоты EN/RU и источников выбраны вручную;
пересечение дополнительно смещает выборку по длине и формату. Wikipedia может содержать
имена людей и чувствительные темы; специальной safety-разметки и аудита PII не проводилось.
Синтетика шаблонная и не предназначена для оценки редких атак. Длина 4096 не означает,
что модель сохранит качество или поместится на конкретном GPU.

На этом наборе можно измерять скорость и долю изменений вердикта относительно baseline.
**Совпадение вердиктов не доказывает сохранение safety.** Для этого нужен отдельный
размеченный набор и согласованные требования. Никаких safety-меток корпус не содержит.
