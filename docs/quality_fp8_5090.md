# Качество FP8 относительно bf16 на RTX 5090

FP8 per-row (torchao 0.17.0, dynamic W8A8, все `nn.Linear` тела модели) против эталона bf16; оба варианта с `torch.compile`.
Набор [tails_v2](tails_v2_composition.md), батч 1, режим `quality` измерителя У1 v4, коммит `f786801`, 2026-11-18.
Сравнение парное: одни и те же строки у эталона и FP8. FNR — по harm-строкам, FPR — по safe-строкам;
p — точный McNemar по сменам вердикта, по техникам — с поправкой Holm.

## Значимые изменения по техникам (Holm, α = 0,05)

**Значимость.** Для каждой техники и стороны (harm → FNR, safe → FPR) берём строки, где вердикт FP8 отличается
от эталона: $b$ — стало хуже (пропуск вредного или новая ложная тревога), $c$ — стало лучше. Изменение значимо,
если перекос между $b$ и $c$ слишком велик для случайных смен в обе стороны (точный McNemar):

$$p = \min\Big(1,\; 2\sum_{i=0}^{\min(b,c)} \binom{b+c}{i}\, 0{,}5^{\,b+c}\Big)$$

Техник $m = 18$, поэтому $p$ корректируется по Holm: при $p_{(1)} \le \dots \le p_{(m)}$

$$p^{\text{Holm}}_{(k)} = \min\Big(1,\; \max_{j \le k}\,(m - j + 1)\, p_{(j)}\Big)$$

Значимо, если $p^{\text{Holm}} < 0{,}05$: вероятность хотя бы одной ложной «значимой» техники среди 18 — не выше 5%.
Строка «весь набор» — одна проверка, без поправки.
